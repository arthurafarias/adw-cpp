#include <adw/adw.hpp>

namespace adw = gi::repository::Adw;
namespace gtk = gi::repository::Gtk;

static void on_activate(adw::Application app) {
    auto window = adw::ApplicationWindow::new_();
    window.set_title("Hello, Adwaita!");
    window.set_application(app);

    auto header = adw::HeaderBar::new_();
    auto view   = adw::ToolbarView::new_();
    view.add_top_bar(header);

    button.signal_clicked().connect([&] {
        toast.set_title("Button clicked!");
        overlay.add_toast(toast);
    });

    window.present();
}

int main(int argc, char *argv[]) {
    auto app = adw::Application::new_(
        "org.example.Hello", {});
    app.signal_activate().connect(
        [app]() mutable { on_activate(app); });
    return app.run(argc, argv);
}

A complete, production-ready C++ interface to the GNOME platform.

⬡

Complete Coverage

~1,900 binding files across 16 namespaces — Adw, Gtk, Gio, GLib, GObject, GDK, Pango, Cairo, Graphene, GSK, and more. Every widget, every signal.

🔒

Type Safety

Strong C++ types wrap the GObject type system. No raw gpointer or GObject* leakage — the compiler enforces correctness.

⚡

Signal & Property Proxies

Connect to any GObject signal or access any property through generated proxy objects with full type information preserved.

♻️

RAII Memory Management

gi::transfer_full and gi::transfer_none track ownership at compile time and prevent memory leaks without runtime overhead.

📦

C++20 Modules

Optional *.cppm module units for each namespace enable faster builds and better dependency isolation in modern toolchains.

🔧

Modern CMake

Exported targets, pkg-config file generation, and find_package(GiRepositoryAdw) support for seamless integration into any CMake project.

🔄

Nullable Overloads

Every method accepting a nullable GObject provides a no-arg overload to pass nullptr — no ambiguity, no casts.

🏭

Auto-Generated

Bindings are auto-generated from GObject Introspection (GIR) metadata via cppgir, ensuring accuracy and completeness.

Get Started

Up and running in minutes.

1

Install dependencies

sudo dnf install libadwaita-devel gtk4-devel graphene-devel cmake
sudo apt install libadwaita-1-dev libgtk-4-dev \
    libgraphene-1.0-dev cmake
sudo pacman -S libadwaita gtk4 graphene cmake

You also need to build and install cppgir separately.

2

Build & install the library

git clone https://github.com/username/adw-cpp
cd adw-cpp
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
sudo cmake --install build
3

Link from your CMake project

find_package(GiRepositoryAdw REQUIRED)

target_link_libraries(my-app PRIVATE
    GiRepositoryAdw::gi-repository-adw-standalone)

API Patterns

Consistent, predictable, and idiomatic C++.

Construction

auto row = adw::ActionRow::new_();
auto win = adw::ApplicationWindow::new_();
auto btn = gtk::Button::new_with_label("Click");

Properties

row.set_title("Username");
row.set_subtitle("Display name");
auto title = row.get_title();

// property_*() returns a GObject property proxy
row.property_title().get_value();

Signals

button.signal_clicked().connect([] {
    g_print("clicked!\n");
});

row.signal_activated().connect([&] {
    handle_row_activated();
});

Nullable overloads

// set an activatable widget
row.set_activatable_widget(some_widget);

// clear it (pass nullptr)
row.set_activatable_widget();

Style Manager

auto mgr = adw::StyleManager::get_default();
mgr.set_color_scheme(
    adw::ColorScheme::FORCE_DARK_);
